VEILLE ACTIVE

C'est quoi la veille technologique ?

En résumé : La veille technologique, c'est le fait de se tenir informé régulièrement des nouveautés dans son domaine. Concrètement, je consulte des sites, des newsletters et des forums pour savoir ce qui change dans le monde du développement web.

Ma veille est active : je ne tombe pas sur ces informations par hasard. Je vais les chercher moi-même, je lis, je trie ce qui est utile, et je note ce que j'apprends.

Pourquoi je fais cette veille

  • Rester à jour sur les outils et langages que j'utilise en cours et en stage
  • Anticiper les changements pour ne pas être pris au dépourvu
  • Mieux choisir les technologies à utiliser dans mes projets
  • Me préparer à travailler en entreprise dans de bonnes conditions

Comment je fais ma veille

  • Je cherche : Je consulte régulièrement des sites fiables et la documentation officielle
  • Je trie : Je garde uniquement ce qui est utile et vérifié
  • J'analyse : Je me demande si ça peut m'aider dans ma formation ou mes projets
  • Je note : Je documente ce que j'apprends, comme ici sur ce portfolio
  • Je pratique : J'essaie d'appliquer ce que j'ai appris dans mes projets concrets

Mes sources

Voici les sites et ressources que je consulte régulièrement :

  • react.dev : La documentation officielle de React — je la lis chaque semaine
  • blog.react.dev : Le blog officiel où sont annoncées les nouveautés — suivi mensuel
  • React Status & JavaScript Weekly : Des newsletters reçues par email avec les actus de la semaine
  • GitHub React : Pour voir les discussions et les nouvelles versions en cours
  • Stack Overflow & Reddit r/reactjs : Pour voir ce que les autres développeurs font et demandent
  • YouTube (React Conf, JS Conf) : Des conférences filmées où des experts présentent les nouveautés
  • Medium, Dev.to, Smashing Magazine : Des articles écrits par des développeurs sur leurs expériences

✓ Je consulte toutes ces sources volontairement et régulièrement dans le cadre de ma formation

Ce que j'ai découvert - React 2025/2026

React 19 & les Server Components

Désormais, une partie du code React peut s'exécuter directement sur le serveur, ce qui allège la page web côté utilisateur. Des outils comme Next.js l'utilisent déjà par défaut.

Impact : ÉLEVÉ

Le hook use() — une nouvelle façon de gérer les données

React 19 introduit une nouvelle fonction appelée use() qui simplifie la façon de récupérer et d'afficher des données dans une application. C'est plus lisible et plus court à écrire.

Impact : MOYEN-ÉLEVÉ

Les Server Actions — envoyer des données plus facilement

Avec React 19, envoyer un formulaire ou modifier des données côté serveur devient beaucoup plus simple. Moins de code à écrire pour faire la même chose qu'avant.

Impact : ÉLEVÉ

Des performances améliorées

React continue d'optimiser la façon dont il met à jour l'interface. Les pages sont plus rapides à charger et plus fluides à utiliser.

Impact : MOYEN

TypeScript de plus en plus utilisé

TypeScript est une version de JavaScript qui oblige à bien typer son code, ce qui évite beaucoup d'erreurs. Il est maintenant quasi incontournable dans les projets React professionnels.

Impact : MOYEN-ÉLEVÉ

Ce que ça change pour moi

Les tendances que j'ai repérées :

  • React cherche à envoyer de moins en moins de code JavaScript au navigateur — les pages sont plus légères
  • Next.js s'impose comme le framework React le plus utilisé en entreprise
  • L'accessibilité (rendre les sites utilisables par tout le monde) et les performances deviennent des critères importants
  • On voit de plus en plus de projets React qui intègrent de l'intelligence artificielle

Ce que j'ai décidé de faire suite à cette veille :

  • ✅ Apprendre Next.js et l'utiliser dans mes prochains projets
  • ✅ Approfondir les hooks React les plus avancés
  • ✅ Essayer les Server Components dans un projet personnel
  • ✅ Travailler sur les performances de mes sites
  • ✅ Commencer à utiliser TypeScript, notamment pour mon stage chez Yusha Tattoo

À quelle fréquence je fais ma veille

  • Tous les jours : Un coup d'œil rapide sur les discussions GitHub React (10-15 min)
  • Chaque semaine : Lecture de la newsletter React Status + quelques articles (30-45 min)
  • Chaque mois : Lecture du blog officiel React + exploration des nouveautés (1-2h)
  • Tous les 3 mois : Lecture des grandes propositions de changements + évaluation de nouveaux outils (2-3h)

Pourquoi c'est important pour mon BTS

  • Ça me permet d'aller plus loin que ce qu'on voit en cours
  • Je suis mieux préparé pour les projets et les examens pratiques
  • En stage, je connais déjà les outils avant même d'arriver
  • En informatique, savoir s'adapter rapidement est une compétence essentielle

Mettre en pratique React 19 et Next.js dans mon stage et mes projets de fin de formation.
