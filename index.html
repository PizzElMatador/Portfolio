� Ce qui change - React 2025/2026

React 19 & Server Components

Les composants serveur simplifient la gestion du state et réduisent le JS client. Next.js les utilise par défaut maintenant.

Hooks plus puissants

La nouvelle API use() rend les async et le contexte plus simples. Moins d'effet de bord à gérer.

Server Actions

Les mutations sans boilerplate. Les formulaires se simplifient pas mal.

TypeScript partout

C'est devenu le standard. Tous les new frameworks ont TS par défaut.

Perf et Core Web Vitals

Le focus reste sur les perfs. Les algo de réconciliation s'améliorent constamment.
