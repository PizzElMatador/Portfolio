Sun & Bass

Plateforme de gestion de prestations et d'utilisateurs

À propos du projet

Sun & Bass est une application web complète développée avec Angular, permettant la gestion de prestations professionnelles et de profils utilisateurs.

L'application offre une interface moderne avec authentification utilisateur, tableaux de bord distincts pour les administrateurs et prestataires, et une gestion complète des prestations via une base de données SQL.

Ce projet démontre mes compétences en développement full-stack avec architecture frontend modulaire et intégration backend.

Stack Technique

Angular TypeScript HTML/CSS SQL API REST

Fonctionnalités principales

  • Système d'authentification utilisateur
  • Tableaux de bord personnalisés par rôle
  • Dashboard Admin
  • Dashboard Prestataire
  • Gestion des prestations
  • Profils utilisateurs
  • Architecture modulaire Angular
  • Intégration API REST
  • Base de données SQL
  • Services métier réutilisables

Structure du projet

Le projet est organisé avec une structure Angular modulaire comprenant:

  • Components: Login, Register, Admin Dashboard, Prestataire Dashboard, Prestations, Profile
  • Services: Auth Service, Admin Service, Prestataire Service, Prestation Service
  • Models: User et Prestation
  • Base de données: Schema SQL pour la persistence des données
